Tip of the Day — #10: Custom slash commands Create .claude/commands/your-command.md in your repo and it becomes a /your-command you can call in any Claude Code session. The file's content becomes the prompt. Check it in with the repo and every engineer on the team gets the same command — no manual setup, no drift. - /security-review — run your standard security checklist against the current diff - /generate-tests — generate unit tests for the last-modified file - /summarize-pr — draft a PR description from the current branch diff Also available in the Claude Code IDE extensions (VS Code, JetBrains) via the command palette. Have You Seen? — #10: Vision support Claude Code reads images. Paste a screenshot into the prompt, drag in a file, or reference a path — Claude analyzes it directly. - UI debugging: screenshot the broken component — Claude identifies the CSS/layout issue - Architecture review: drop in a diagram — Claude reads it and gives feedback or generates code from it - Error triage: screenshot an obscure error — Claude identifies the root cause faster than copying log text - Design-to-code: share a mockup — Claude generates a component skeleton Pair with `claude --print` and a screenshot tool in CI for automated visual regression checks.
