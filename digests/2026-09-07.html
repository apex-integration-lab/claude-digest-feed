📄 Docs Changes

September 3 — ant CLI v1.30.0 adds ant apply

The ant apply command lets you manage agents, environments, skills, memory stores, and deployments from config files in your repo. Describe each resource in a file, run ant apply, and it prints a plan for approval. The resulting claude-lock.json lockfile ensures CI and teammates update the same resources — no drift. Think Terraform, but for Claude infrastructure.

💡 Tip of the Day

Claude Code in CI

Run claude --print non-interactively in scripts and CI pipelines. Useful for automated code review, doc generation, or changelog drafting on each PR — no human in the loop required. Pair it with --output-format json if you need structured output downstream.

👀 Have You Seen?

Claude Code /review command

Claude Code has a built-in PR review command. Run /review on an open diff and Claude reads the changes, flags bugs and simplification opportunities, and can post inline GitHub comments — no third-party code review tool needed. It’s aware of your repo context (CLAUDE.md, recent history) so the feedback is specific, not generic.
