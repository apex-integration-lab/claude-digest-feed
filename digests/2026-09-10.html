🆕 What's New

Claude Code v2.1.268 dropped yesterday. Key highlights:

  • Gateway pricing in managed settings — /cost and telemetry now match your actual spend meter. Cost governance without manual reconciliation between the client and billing dashboard.
  • Security warnings for open gateway CIDR — Startup warning when access_control.allow_cidrs is empty, plus a one-time alert on the first public-IP request. Proactive hardening for teams that left gateway access wide open.
  • Plugin management --json — install, uninstall, enable, disable all now support --json output. Enables CI/CD automation for org-wide plugin lifecycle management.
  • remove-session-state for self-hosted runner — Cleans up per-session directories on exit; useful for CI/CD environments with privacy requirements.
  • ⚠️ Fix: HTTP 400 regression on ANTHROPIC_BASE_URL — Every turn was failing on Bedrock, Vertex, Foundry, or any custom base URL since v2.1.265. Three-release regression. Update immediately if you're using custom endpoints.

Also out: Anthropic Threat Intelligence Report — September 2026. Documents how threat actors have attempted to misuse Claude and how those operations were disrupted.

📋 Docs Changes

Sep 10 — Managed Agents permission policies now support auto mode: the server evaluates each tool call and can run, deny, or hold for approval. New ant beta:sessions connect lets you attach your terminal to a live agent session and approve/deny tool calls in real time.

Sep 3 — ant apply brings GitOps to Claude Managed Agents: define agents, environments, and deployments in files, apply with one command, version-lock in claude-lock.json. Per-message effort control now available on Google Cloud for Fable 5.1, Mythos 5.1, and Opus 5.

💡 Tip of the Day

#12 — Project settings in .claude/settings.json

Lock in which tools Claude can use, which files it can't touch, and what always needs human confirmation. Keeps auto-mode powerful but safe in sensitive repos — no need to choose between speed and control.
