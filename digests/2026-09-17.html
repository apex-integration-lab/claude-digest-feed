💡 Tip of the Day — #19

Voice input works in Claude Code

On desktop, use your OS voice-to-text to dictate prompts directly into Claude Code. Especially useful during long debugging sessions when you're describing what you're seeing rather than what the code says — narrating observation is faster than typing it.

👀 Have You Seen? — Prompt Caching

Large, stable contexts — system prompts, reference docs, big codebases — can be cached server-side at ~10% of normal token cost. Add cache_control: {type: "ephemeral"} to any content block you want cached. The cache persists for 5 minutes (extended to 1 hour with the extended-cache beta).

Essential before any high-volume production deployment. Break-even is low: if the same context appears in more than ~10 calls, caching saves money on every subsequent call.
