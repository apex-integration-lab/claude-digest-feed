Claude Daily Digest — Thu, Sep 3

📦 What's New

Claude Code v2.1.259 dropped last night:

  • managedMcpServers — Organizations can push HTTP/SSE MCP servers to all users via policy (same shape as .mcp.json). The enterprise path for giving every engineer access to shared internal tools without per-user setup.
  • Concurrent session fix — Running multiple Claude Code sessions in parallel was silently corrupting ~/.claude.json, resetting workspace trust and losing MCP state. Now fixed — parallel tmux/terminal workflows are safe.
  • Also: --permission-prompts none for Headless CI runners, GitLab MR badge support (glab mr commands), improved Bash sandboxing for deny rules.
