💡 Tip of the Day

#20 — Claude Code tracks what it changed

After a session, run git diff to see every file Claude touched. Review the diff before committing — this is the moment to catch anything you'd tweak. Claude Code is thorough, but a quick scan keeps you in the loop on your own codebase.
