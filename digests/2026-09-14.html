🆕 What's New

Two Claude Code releases landed today:

v2.1.271 — Three standouts:

  • Fast mode in Remote sessions — /fast now works in cloud and self-hosted runner sessions (org policy permitting). Previously desktop-only.
  • Per-command allowed_domains — Bash/PowerShell commands in auto mode can declare exactly which network hosts they need; all others are refused. The right model for enterprise sandbox config.
  • omitClaudeMd for subagents — Plugin subagents can run without loading user/project CLAUDE.md files. Keeps agent context clean and portable when building internal tooling.

v2.1.272 — Bug fixes and reliability improvements.

📄 Docs Changes

Sep 10 — Claude Managed Agents updates:

  • Auto permission evaluation — Managed Agents now support an auto mode that evaluates each agent/MCP tool call and runs, denies, or pauses for approval in real time.
  • Terminal session attachment — ant beta:sessions connect lets you attach your terminal to a live Managed Agents session: follow along, send messages, and allow/deny tool approvals interactively.

💡 Tip of the Day #16

claude --model to pick your tier

Match the model to the task: --model haiku for fast, cheap iteration on simple tasks; --model sonnet for the daily workhorse; --model opus for the hard stuff. Need to switch mid-session? Just type /model.

👀 Have You Seen?

Claude Code auto mode

Fully autonomous agentic execution — Claude handles tool permissions, runs tests, fixes failures, and iterates without prompting you at each step. Toggle it with /auto. Best for well-scoped tasks where you trust the direction; Claude will plan, execute, and self-correct until the job is done.
