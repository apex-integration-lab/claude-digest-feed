What's New

Claude Code v2.1.273 released Sep 15. Key changes:

  • Gateway hint headers — Claude Code sends metadata headers to help MCP servers understand the calling context
  • MDM settings fix — MDM-managed config was being ignored on first launch; now resolved
  • Bash permission bypass fix — closes a path where bash tool calls could skip permission checks in certain auto-mode scenarios
  • Session forking from Remote Control — fork a running session into a new branch from the Remote Control interface

Docs Changes

Sep 14: Messages API compaction on demand (beta) — trigger conversation compaction manually and receive a signed compaction block summarizing prior messages. Enable with the compact-2026-09-04 beta header. Useful for long-running agentic sessions.

Tip #17 — Git-Aware by Default

Claude Code reads your git history, branch diffs, and blame automatically. Ask it “what changed in the last 3 commits that could explain this bug?” and it digs through the log — no extra setup needed. Especially useful when debugging a regression where you know roughly when it appeared but not why.
