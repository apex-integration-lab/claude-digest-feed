🆕 What's New

Claude Code v2.1.269 dropped with two headline features:

  • Plugin eval suite — built-in harness for testing and benchmarking Claude Code plugins ⭐
  • WORKFLOW_MAX_CONCURRENT_AGENTS (1–256) — tune parallelism for multi-agent workflows; default stays 10 ⭐
  • Bash diff output improvements, OTel vcs.* tagging for observability, and a prompt cache correctness fix

📄 Docs Changes

ant beta:sessions connect — Attach your terminal to a live Managed Agents session to follow progress, send messages, and approve/deny tool calls. Add --web to serve the session viewer locally. Read the docs →

💡 Tip of the Day

#13 — Inline /review for PRs

Run /review on an open PR and Claude reads your diff, flags bugs and simplification opportunities, and can post inline GitHub comments — no separate code review tool required. It integrates cleanly into a Claude Code session where you're already making changes.

Constitutional AI — Anthropic's core training technique, published as open research, lets Claude self-critique against a set of principles rather than relying purely on human feedback. Why it matters for practitioners: the principles Claude weighs internally mirror the kind of explicit guidance you provide in system prompts.
