# claude-digest-feed

RSS feed for the Claude AI daily digest, served via GitHub Pages.

## Feed URL

```
https://apex-integration-lab.github.io/claude-digest-feed/digest.xml
```

## How it works

The `digest.xml` file is a standard RSS 2.0 feed published here by an automated agent (Mikey). Subscribe to the feed URL in any RSS reader to receive daily Claude AI digests.

## Files

- `digest.xml` — the RSS feed (updated automatically, do not edit manually)
- `README.md` — this file
